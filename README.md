<h2>⚡ What I Do</h2>

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>🧮 Size and analyze</h4>
      Build parametric models that set thrust, mass, and run time before any metal is cut. FEA and CFD to confirm the model.
    </td>
    <td width="50%" valign="top">
      <h4>📐 Design and detail</h4>
      Creo models and manufacturing ready drawings. Compliant mechanisms, pressure plumbing, nozzles and manifolds.
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4>🔌 Board and loop</h4>
      Schematic capture and layout in KiCad and Ultiboard. Sensor selection, actuator sizing, and control loop design and tuning.
    </td>
    <td width="50%" valign="top">
      <h4>🔥 Make the parts</h4>
      MIG, TIG, and stick welding. Manual lathe and mill. I build the hardware I draw, so the drawings are buildable.
    </td>
  </tr>
</table>
